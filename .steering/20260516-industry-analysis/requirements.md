# 要求内容：業種別分析の追加

## 背景

現在の `analyze` コマンドはすべての業種を混合して分析している。
業種ダミー（小売業D）はラグ回帰で「定数列のため除外」されており、
小売業・情報通信業それぞれの傾向を把握できていない。

## 要求

### A. 業種別フィルタ（--industry オプション）

- `analyze` コマンドに `--industry retail / it / all` オプションを追加する
- `retail` → 小売業（sector33Code=6100）のみに絞り込んで全分析を実行
- `it`     → 情報通信業（sector33Code=5250）のみに絞り込んで全分析を実行
- `all`    → 現状と同じ（デフォルト）

### B. 業種×キーワード交差項（MultiModelAnalyzerの拡張）

- `MultiModelAnalyzer` の変数探索に交差項仕様を追加する
- 具体的には `dxScore×IT_dummy` / `aiScore×IT_dummy` / `dxScore×retailDummy` 等を説明変数に含む仕様を追加
- 交差項の係数・p値により「業種によってキーワード効果が異なるか」を検証する

## 期待する出力

- レポートに業種別セクション（またはフィルタ済みレポート）が追加される
- 交差項の係数と有意性が変数探索テーブルに出力される
