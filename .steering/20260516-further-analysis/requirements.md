# 要求内容：追加分析3件

## 背景

業種別分析（20260516-industry-analysis）の結果として、
以下3点が今後の分析候補として浮上した。

## 分析① UNKNOWN業種の除外

### 問題
全業種11,947件中 約2,400件が sector33Code='UNKNOWN'（未分類）。
これらが全業種の集計結果（特にdxScore→ROAの正効果）を歪めている可能性がある。

### 要求
`analyze` コマンドに `--exclude-unknown` フラグを追加する。
このフラグを指定した場合、sector33Code='UNKNOWN' の企業を除外してすべての分析を実行する。
`--industry` フラグと組み合わせ可能とする。

---

## 分析② 情報通信業の逆因果検証

### 問題
情報通信業では「AIスコア→翌期営業利益率 負」が有意。
ただし逆因果（業績悪化企業がAI/DX言及を増やす）の可能性が排除できていない。

### 要求
VariableSpec に「前期業績値をコントロール変数に含む仕様」を追加する。
具体的には以下のコントロールセットを追加:
- log(売上高) + 前期営業利益率 + 小売業D
- log(売上高) + 前期ROA + 小売業D

前期業績をコントロールした上でもキーワード係数が負に有意であれば、
逆因果よりも投資コスト仮説が支持される。

---

## 分析③ 小売業の二値言及変数

### 問題
小売業では全企業の genAiScore=0、dxScore も大半がゼロ。
連続変数ではなく「言及あり（1） / なし（0）」の二値変数として分析すべき可能性。

### 要求
MergedRecord に以下の二値変数メソッドを追加する:
- `dxMention()`  : dxScore > 0 なら 1.0、そうでなければ 0.0
- `aiMention()`  : aiScore > 0 なら 1.0
- `anyMention()` : totalScore > 0 なら 1.0

これらを VariableSpec のキーワード変数として追加し、
小売業・情報通信業・全業種で変数探索の対象に含める。
